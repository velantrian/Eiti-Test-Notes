# Технологии и программирование | Technology & programming
что такое алгоритм || Алгоритм — конечная последовательность чётких шагов для решения задачи. Слово происходит от имени учёного IX века аль-Хорезми.
big o нотация; сложность алгоритма о большое || О-нотация описывает, как растёт время или память с ростом входа n: O(1) — константа, O(log n) — бинарный поиск, O(n) — проход по списку, O(n log n) — хорошие сортировки, O(n²) — вложенные циклы.
бинарный поиск || Бинарный поиск ищет элемент в отсортированном массиве, каждый раз деля диапазон пополам: O(log n). Для миллиона элементов нужно не больше ~20 сравнений.
сортировки какие бывают; быстрая сортировка || Популярные сортировки: быстрая (quicksort, в среднем O(n log n)), слиянием (merge sort, стабильная, O(n log n)), пирамидальная (heapsort), вставками (хороша для почти отсортированных данных). Встроенные сортировки часто используют гибриды (Timsort, introsort).
стек и очередь разница || Стек — LIFO («последним пришёл — первым ушёл»), как стопка тарелок. Очередь — FIFO («первым пришёл — первым ушёл»), как очередь в магазине.
хеш таблица что это || Хеш-таблица хранит пары ключ–значение и находит значение по ключу в среднем за O(1) с помощью хеш-функции. Примеры: dict в Python, Map и объекты в JavaScript.
рекурсия что это || Рекурсия — когда функция вызывает саму себя для меньшей подзадачи. Нужен базовый случай, иначе будет бесконечный вызов и переполнение стека. Пример: факториал n! = n·(n−1)!.
что такое api || API (Application Programming Interface) — набор правил, по которым программы обмениваются данными и командами. Веб-API обычно работают по HTTP и возвращают JSON.
rest api методы http; get post put delete || Основные методы HTTP в REST: GET — получить, POST — создать, PUT/PATCH — изменить, DELETE — удалить. GET не должен менять данные.
коды ответа http; 404 500 || Коды HTTP: 2xx — успех (200 OK, 201 Created), 3xx — перенаправление (301, 302, 304), 4xx — ошибка клиента (400, 401 — не авторизован, 403 — запрещено, 404 — не найдено, 429 — слишком много запросов), 5xx — ошибка сервера (500, 502, 503).
что такое json || JSON — текстовый формат данных: объекты {"ключ": значение}, массивы [], строки, числа, true/false, null. Ключи обязательно в двойных кавычках, комментарии не допускаются.
git основные команды; как пользоваться git || Основное в git: git clone (скачать репозиторий), git status, git add (подготовить изменения), git commit -m "..." (зафиксировать), git pull (получить), git push (отправить), git branch / git switch (ветки), git merge (слить), git log (история).
git merge и rebase разница || git merge объединяет ветки, создавая коммит слияния и сохраняя историю как есть. git rebase переносит ваши коммиты поверх другой ветки, делая историю линейной; опубликованные общие ветки ребейзить не стоит.
как отменить последний коммит git || Отменить последний коммит, оставив изменения в файлах: git reset --soft HEAD~1. Если коммит уже отправлен в общий репозиторий, безопаснее git revert <хеш> — он создаёт обратный коммит.
pull request что это || Pull request (merge request) — запрос на слияние изменений из одной ветки в другую с обсуждением и ревью кода; на GitHub и GitLab к нему привязываются автоматические проверки (CI).
python что за язык || Python — высокоуровневый язык с простым синтаксисом и отступами вместо скобок. Создан Гвидо ван Россумом (первый выпуск 1991). Популярен в анализе данных, ИИ, автоматизации, вебе.
javascript и java разница || JavaScript и Java — разные языки, общего у них в основном название. JavaScript работает в браузере и на Node.js, динамически типизирован; Java компилируется в байт-код для JVM и статически типизирована.
javascript let const var разница || В JavaScript: const — переменную нельзя переприсвоить (но объект внутри можно менять), let — можно переприсвоить; обе с блочной областью видимости. var — устаревший вариант с функциональной областью видимости и «поднятием».
что такое html css || HTML задаёт структуру и содержимое страницы (заголовки, абзацы, ссылки), CSS — внешний вид (цвета, шрифты, расположение), JavaScript — поведение и интерактивность.
что такое sql; основные запросы sql || SQL — язык запросов к реляционным базам данных. Основное: SELECT ... FROM ... WHERE (выбрать), INSERT (вставить), UPDATE (изменить), DELETE (удалить), JOIN (соединить таблицы), GROUP BY (группировка).
sql инъекция || SQL-инъекция — атака, при которой ввод пользователя попадает прямо в SQL-запрос и меняет его смысл. Защита: параметризованные запросы (prepared statements), не склеивать SQL из строк.
xss атака || XSS (межсайтовый скриптинг) — внедрение вредоносного JavaScript в страницу через неэкранированный ввод. Защита: экранирование вывода, Content Security Policy, не вставлять пользовательский текст через innerHTML.
что такое pwa || PWA (прогрессивное веб-приложение) — сайт, который можно установить как приложение: работает офлайн через Service Worker, имеет манифест с иконкой и открывается в отдельном окне.
service worker что это || Service Worker — скрипт, который браузер запускает в фоне отдельно от страницы. Он перехватывает сетевые запросы и может отдавать ответы из кеша, что даёт работу офлайн и push-уведомления.
localstorage и indexeddb разница || localStorage — простое синхронное хранилище строк (обычно около 5 МБ), блокирует поток при больших объёмах. IndexedDB — асинхронная база в браузере для больших объёмов и структурированных данных, не тормозит интерфейс.
что такое кеш || Кеш — быстрое хранилище копий часто используемых данных, чтобы не получать их заново. Бывает кеш процессора, браузера, CDN, приложений.
оперативная память и постоянная разница; ram ssd || Оперативная память (RAM) быстрая, но очищается при выключении — в ней работают программы. Постоянная память (SSD, HDD) хранит файлы после выключения. SSD намного быстрее HDD, потому что в нём нет движущихся частей.
бит и байт; сколько бит в байте || 1 байт = 8 бит. Килобайт по СИ — 1000 байт, а кибибайт (КиБ) — 1024 байта; в операционных системах «КБ/МБ/ГБ» часто означают степени 1024.
двоичная система счисления || В двоичной системе только цифры 0 и 1. Например, 5 = 101₂, 10 = 1010₂, 255 = 11111111₂. Шестнадцатеричная (0–9, A–F) удобна для записи байтов: 255 = FF.
что такое ip адрес; ipv4 ipv6 || IP-адрес — адрес устройства в сети. IPv4 — 32 бита (например, 192.168.1.1), около 4,3 млрд адресов; IPv6 — 128 бит (например, 2001:db8::1).
dns что это || DNS — «телефонная книга интернета»: переводит доменные имена (example.com) в IP-адреса.
что такое vpn || VPN создаёт зашифрованный туннель между устройством и сервером VPN: скрывает трафик от локальной сети и провайдера, но владелец VPN-сервиса может видеть, куда вы ходите.
https и http разница || HTTPS — это HTTP поверх шифрования TLS: данные между браузером и сайтом нельзя прочитать или незаметно подменить по пути. Замок в адресной строке не гарантирует, что сайт честный.
что такое облако; облачные вычисления || Облачные вычисления — использование чужих серверов через интернет: хранение (Google Диск, iCloud), вычисления и сервисы (AWS, Azure, Google Cloud) с оплатой по мере использования.
искусственный интеллект что это; машинное обучение || Искусственный интеллект — область создания систем, решающих задачи, требующие «интеллекта». Машинное обучение — подход, когда модель учится закономерностям на данных, а не программируется правилами вручную. Глубокое обучение использует многослойные нейросети.
нейросеть как работает || Искусственная нейросеть — слои «нейронов», каждый суммирует входы с весами и применяет нелинейную функцию. Обучение подбирает веса так, чтобы уменьшить ошибку на примерах (обратное распространение ошибки и градиентный спуск).
большая языковая модель llm || Большая языковая модель (LLM) — нейросеть-трансформер, обученная на огромном объёме текста предсказывать следующий фрагмент (токен). Она может ошибаться и уверенно выдумывать факты («галлюцинации»), поэтому важное стоит проверять.
что такое трансформер в нейросетях || Трансформер — архитектура нейросетей (статья «Attention Is All You Need», 2017) на основе механизма внимания: модель учитывает связи между всеми словами последовательности. Основа современных языковых моделей.
что такое open source; открытый исходный код || Open source — программы с открытым исходным кодом, который можно изучать, изменять и распространять по условиям лицензии (MIT, Apache, GPL и др.). Примеры: Linux, Firefox, Python.
linux что это || Linux — семейство открытых операционных систем на ядре Linux (Линус Торвальдс, 1991). Ubuntu, Debian, Fedora — популярные дистрибутивы; на Linux работает большинство серверов и Android.
основные команды linux терминал || Основные команды терминала Linux: ls (список файлов), cd (сменить папку), pwd (где я), cp/mv/rm (копировать/переместить/удалить), mkdir (создать папку), cat/less (показать файл), grep (поиск в тексте), sudo (от имени администратора).
регулярные выражения основы || Регулярные выражения — шаблоны для поиска текста: . — любой символ, * — 0 и более, + — 1 и более, ? — 0 или 1, \d — цифра, \w — буква/цифра, ^ и $ — начало и конец строки, [abc] — один из символов, (…) — группа.
ооп принципы; инкапсуляция наследование полиморфизм || Принципы ООП: инкапсуляция (данные и методы вместе, скрытие деталей), наследование (класс расширяет другой), полиморфизм (один интерфейс — разные реализации), часто добавляют абстракцию.
solid принципы || SOLID: S — одна ответственность у класса; O — открыт для расширения, закрыт для изменения; L — подстановка Барбары Лисков; I — разделение интерфейсов; D — инверсия зависимостей.
что такое docker || Docker упаковывает приложение со всеми зависимостями в контейнер, который одинаково запускается на любом компьютере с Docker. Контейнеры легче виртуальных машин: они используют ядро хост-системы.
юнит тесты зачем || Юнит-тесты автоматически проверяют маленькие части кода. Они ловят регрессии при изменениях и служат документацией. CI запускает тесты на каждый коммит или PR.
что такое ci cd || CI (непрерывная интеграция) — автоматическая сборка и тесты при каждом изменении. CD — автоматическая доставка или развёртывание проверенного кода. Примеры: GitHub Actions, GitLab CI.
что такое юникод utf-8 || Юникод — единая таблица символов всех письменностей (больше 150 000 символов). UTF-8 — самая распространённая кодировка Юникода: латиница занимает 1 байт, кириллица 2, эмодзи 4.
первый компьютер; эниак || Одним из первых электронных универсальных компьютеров был ENIAC (США, 1945–1946). Механическую «аналитическую машину» задумал Чарльз Бэббидж в 1830-х, а первые программы для неё написала Ада Лавлейс.
закон мура || Закон Мура (Гордон Мур, 1965, уточнён в 1975): число транзисторов на микросхеме удваивается примерно каждые два года. В последние годы рост замедлился.
кто создал интернет; www бернерс ли || Предшественник интернета — ARPANET (США, 1969). Протоколы TCP/IP созданы Винтом Серфом и Робертом Каном; в ARPANET перешли на них 1 января 1983 года. Всемирную паутину (WWW) придумал Тим Бернерс-Ли в CERN в 1989–1991 годах.
отладка кода как искать ошибку || Как искать баг: воспроизвести стабильно, прочитать сообщение об ошибке и стек вызовов, сузить место (логи, точки останова, бинарный поиск по коммитам — git bisect), проверить предположения по одному, написать тест на исправленную ошибку.
typescript зачем || TypeScript — надстройка над JavaScript со статическими типами. Ошибки типов ловятся ещё до запуска, а редактор лучше подсказывает. Компилируется в обычный JavaScript.
null и undefined разница javascript || В JavaScript undefined — «значение не присвоено» (переменная объявлена без значения, отсутствующее свойство), null — явное «пустое значение», которое присваивают намеренно. null == undefined истинно, null === undefined ложно.
async await promise || Promise — объект будущего результата асинхронной операции. async/await — синтаксис поверх промисов: await приостанавливает async-функцию до готовности результата, не блокируя поток. Ошибки ловятся через try/catch.
