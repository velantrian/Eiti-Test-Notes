# REPORT-offline-03 — аудит-пакет офлайн-движка для PR #59

## Что добавлено

В Draft PR #59 включены [исследовательский синтез](RESEARCH-02.md) и [эскиз архитектуры офлайн-движка](OFFLINE_ENGINE_ARCHITECTURE.md). В `velantrim_core/tests_js/offline/` лежат 130 синтетических одноходовых формулировок, отдельный набор из 7 многоходовых диалогов и CSV baseline текущего парсера. Новый `frames_offline_audit_baseline.test.js` проверяет уникальность фраз, формат диалогов и совпадение всех строк CSV с результатом Frames на исходной ветке.

## Как читать результаты

Поле `expect.intent` в JSON — целевая смысловая метка для аудита, не утверждение, что Frames уже выдаёт такой ID. Из 130 фраз текущий парсер вернул метку для 86 и `null` для 44. Это не accuracy и не pass rate: baseline фиксирует текущее поведение при пустом состоянии. Семь диалогов требуют контекста и поэтому в этот baseline не входят.

В архитектурной заметке текущие KB-пороги отделены от предложенных гипотез. Пороговые значения для будущего `confidence` не являются реализованной функцией или измеренной точностью. Верхний уровень примера пакета карточек исправлен на фактическую схему v2.
